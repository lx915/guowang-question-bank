# 国家电网 2027 届一批 · 企业文化题库

> 国网考生习惯把这部分叫「企业文化题库」。它的官方名称是**《国家电网有限公司高校毕业生招聘考试公共与行业知识题库（2027版）》**，是 2027 届高校毕业生招聘（第一批）笔试公共与行业知识模块的官方固定题库——**题目基本原样考，背到就是分**。

本项目把这份 160 页的 PDF 整理成了**结构化 JSON**和一个**双击即开的本地答题系统**，用来在电脑上高效刷完这 832 道题。

## 为什么值得专门刷

国网笔试共 165 题 / 180 分钟，专业知识占 80 分，公共与行业知识占 20 分。其中企业文化与形势政策各约 5 分，考的就是这本固定题库里的内容，性价比最高、不需要理解只需要记住。本仓库覆盖的正是这部分（不含行测与资料分析）。

## 使用方法

### 方式一：直接刷题（推荐）

1. 双击 `答题系统/index.html`，用 Chrome 或 Edge 打开
2. 首页点「继续上次」，或按**题型 × 板块 × 范围**筛选题目后点「开始练习」
3. 键盘作答，不用点鼠标

| 按键 | 作用 |
| --- | --- |
| `1`–`4` 或 `A`–`D` | 选择选项（单选/判断点完即判，多选题需提交） |
| `Enter` | 提交多选答案 / 下一题 |
| `←` `→` | 上一题 / 下一题 |
| `F` / `M` | 收藏 / 标记存疑 |
| `空格` | 背题模式下翻下一条 |
| `Esc` | 返回 / 关闭弹层 |

系统自带：断点续做、答题卡跳转、背题模式、错题本、1/3/7/21 天复习排期、正确率统计、题号与关键词搜索、进度导出导入。

**无需安装、无需联网、无需服务端，仅在本机电脑上使用。** 进度存在浏览器本地，换电脑前先点「导出进度」备份。

### 方式二：自己处理数据

直接读 `国家电网公共与行业知识题库-2027.json`：

```json
{
  "meta": { "title": "...", "total": 832, "counts": { "single": 352, "multiple": 253, "judge": 227 } },
  "questions": [
    {
      "id": 1,
      "type": "single",
      "typeName": "单选题",
      "section": "形势政策",
      "stem": "习近平新时代中国特色社会主义思想，是（ ）、二十一世纪马克思主义……",
      "options": [ { "key": "A", "text": "当代中国马列主义" } ],
      "answer": ["B"]
    }
  ]
}
```

`answer` 统一为数组（单选、判断也放在数组里），`type` 取值 `single` / `multiple` / `judge`。

### 方式三：核对原文

按 `id`（即原题号）回查 PDF 对应页；答题界面每道题也会显示「原题号 N」，方便定位。
